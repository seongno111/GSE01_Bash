# 주인공 — 후드를 쓴 등불 여행자 v1

2026-10-26. 기존 v3와 같은 3등신 로우폴리 다크 판타지 스타일의 주인공 모델이다.

- 얼굴이 드러나는 후드와 종아리까지 내려오는 넓고 해진 망토
- 양 어깨의 겹판 철제 견갑, 어두운 천 상의와 가죽 벨트
- 가죽 바지·가죽 완갑·장갑·여행용 부츠
- **왼손 램프 / 오른손 롱소드**

후드 안의 실제 머리를 유지했다. 머리·후드·망토·견갑·팔다리·검신·검 손잡이·램프 프레임·램프 불꽃을 별도 메시로 구성했다. 전체 메시 이름은 `HERO_`로 시작하며, `hero_catalog.json`의 `part_id`와 `mesh`가 파트별 참조 기준이다. NPC 카탈로그의 슬롯 번호를 변경하지 않는 독립적인 주인공 프리셋이다.

2026-10-26 망토 수정: `HERO_CAPE_00_WornMantle`의 이름과 part_id를 유지하며 어깨에서 종아리까지 이어지는 폭 0.94m의 망토로 교체했다. 양면 두께·주름·불규칙한 밑단을 모델링하고 기존 chest/hips/제의 본에 웨이트를 연결했다. 원본·GLB·미리보기는 함께 갱신했다.

## 크기와 조립

기본 신장 1.8m, 후드 최고점 약 1.96m다. 모든 메시의 원점은 발바닥 중앙이며 로컬 이동·회전은 0, 스케일은 1로 사용한다. Blender는 미터·Z 위·정면 -Y, GLB는 미터·Y 위·정면 +Z다. 좌우 표기는 캐릭터 자신의 기준이다.

프레임·불꽃을 포함하는 램프는 왼손에, 검신·가드·손잡이는 오른손에 연결했다. 롱소드는 양날의 마름모 단면을 가지며 기본 자세에서 앞으로 기울여 들고 있다. 후드와 견갑은 별개 메시라서 후속 작업에서 교체할 수 있다.

## 리깅과 애니메이션

v3 공용 뼈대의 31개 본 이름과 바인드 좌표를 유지하고, 왼손 아래에 `lamp_pivot`, `lamp_body`를 추가한 33개 본을 사용한다. NPC용 본 이름을 바꿀 필요 없이 기존 클립을 참고할 수 있다. 몸통과 망토에는 복수 본 웨이트를 사용하며, 단단한 견갑·무기·램프 프레임은 해당 본에 연결했다.

주인공이 양손 장비를 들고 있는 자세에 맞춰 기존 NPC 클립을 조정했다. 왼팔은 램프를 안정적으로 들고, 오른팔은 긴 검이 바닥으로 향하지 않도록 조정했다. 램프의 수직 유지와 작은 흔들림도 **키프레임**이다. 물리 시뮬레이션은 아니다.

포함한 17개 클립:

- `HERO_Idle`, `HERO_Walk`, `HERO_Run`
- `HERO_MoveStart`, `HERO_MoveStop`
- `HERO_Turn_L45`, `HERO_Turn_R45`, `HERO_Turn_L90`, `HERO_Turn_R90`, `HERO_Turn_L180`, `HERO_Turn_R180`
- `HERO_AttackLongsword`, `HERO_Guard`, `HERO_Hit`, `HERO_Death`, `HERO_GetUp`
- `HERO_LampInspect`

60fps 타임라인의 본 위치·회전 키프레임이며 GLB 안에 애니메이션을 포함했다. 이동은 제자리 클립이다. 방향 전환은 root 회전 델타를 가진 단발 클립이므로 actor 회전과 이중으로 적용하지 않는다. 검 공격의 접촉 이벤트는 시작 후 0.4초이며 게임 판정 코드는 포함하지 않는다.

원본의 `HERO_RIG`와 `HERO_PARTS`가 주인공 에셋이다. `SOURCE_RIG`는 숨겨 둔 기존 NPC 동작 참고용 뼈대이며 GLB에 포함하지 않았다. `PRESENTATION`과 DISPLAY 오브젝트도 전시용이며 게임 에셋이 아니다. 기본 Action은 `HERO_Idle`이고, 다른 동작은 Action Editor에서 선택할 수 있다. 같은 이름의 NLA 트랙은 기본 mute 상태다.

## 램프의 빛

램프는 철제 프레임과 황동 손잡이, 실제 발광 메시를 가진 열린 케이지 형태다. 유리나 외부 텍스처에 의존하지 않는다. 추가로 `LIGHT_HERO_Lantern` 점광원을 GLB의 `KHR_lights_punctual` 확장으로 넣었다. 엔진에서 이 확장을 지원하면 사용할 수 있으며, 지원하지 않더라도 발광 메시 자체는 남는다. 실시간 주변광·블룸·노출은 적용 환경에서 결정한다.

## 검수와 범위

메시 이름의 중복, 정점 웨이트 합계, GLB 스킨·클립·실제 머리와 램프 광원 포함 여부를 검사하고 실제 모델 렌더로 외형과 소지품 위치를 확인했다. GLB를 새 장면에 다시 가져와 33개 본과 17개 Action이 복구되며 Walk 재생 시 메시가 실제로 변형되는 것도 검사했다. 추가 검사 결과는 `validation.json`을 기준으로 한다.

게임 코드 수정·빌드·플레이어 적용은 진행하지 않았다. 충돌체·LOD·실시간 천 물리도 포함하지 않는다. 기존 v3 파일은 수정하지 않고 별도 주인공 에셋으로 전달한다.

# 마을 외부 설정 기반 3D 청크 지형

2026-11-02. 기준은 **[월드 외곽 청크 지형 설정](../../doc/월드_외곽_청크_지형_설정_2026-11-02.md)**과 `doc/world_biomes.design.json`이다. 문서의 고정 ID·36개 변형 이름·청크 8×8·3칸 주 통행로·여러 청크 장소·16칸 전이·보호 영역 규칙을 카탈로그에 반영했다. 읽은 문서의 스냅샷과 SHA256을 함께 보관했다.

**타일별 오브젝트가 아니라 청크마다 지면 메시 1개**다. 그 메시 안에 지면, 낮은 풀·갈대·자갈, 밭둑·층암·잔해 등 고정 디테일을 합쳤다. 지면마다 OPAQUE 재질 하나와 COLOR_0 정점 색을 사용해 GLB primitive도 하나다. 외부 이미지 텍스처는 없다. 나무 수관처럼 가림 처리와 공유 인스턴싱이 필요한 큰 소품은 별도 공유 모델로 준비했다.

## 문서와 제작물 대응

| 구분 | 내용 | 실제 지면 메시 수 |
|---|---|---:|
| 기본 지형 | 6종 × 문서의 4변형 | 24 |
| 장소 | 4종 × 문서의 3변형; 변형마다 2×2청크 | 48 |
| 지형 전이 | 허용된 주요 이웃 8쌍; 2청크/16칸 폭 | 16 |
| 합계 | 기본/장소 36변형 + 전이 8조합 | 88 |

큰 장소 하나를 8×8 안에 축소하지 않았다. 폐촌·수도원·전장·납골 채석장은 각각 16×16의 4개 청크로 조립한다. 하나의 장소 ID 아래 각 청크를 한 번씩 배치하고, 우물·회랑·봉인판 같은 공유 소품도 소유 청크에서 한 번만 배치하는 예시다. 장소 바닥은 예시 기본 지형에 맞춰 구웠다. 다른 기후에 조합하려면 바닥 색/장식의 다른 베이크나 통합 지형 생성이 필요하며 자동 생태/사건 생성 기능은 아니다.

기본 지형의 차이는 다음과 같다.

- **재바람 초지:** 회녹색 흙, 누런 낮은 풀, 굽은 밭둑·돌, 과수 잔해와 갈림길.
- **검은 수관림:** 어두운 숲 바닥, 굵은 뿌리와 살아 있는 겹 수관, 빈터·풍도목·가시 외곽.
- **종울음 늪지:** 검은 얕은 수면 표현, 갈대, 마른 둑길, 잠긴 종과 묘표·발판. 보라색은 작은 오염 강조에 제한했다.
- **유리재 사막:** 뼛빛 재 지면, 낮은 사구, 검은 유리 노출과 묻힌 수로·바람막이.
- **왕도 구릉:** 차가운 층암·절단면·석축, 망루·석교 교대, 수레 흔적. 실제 통행 높이는 평면으로 유지한다.
- **화덕 황무지:** 검은 흙·숯 기둥, 식은 화덕, 불탄 보급 흔적과 드문 붉은 균열. 지형 전체를 발광시키지 않았다.

나무·돌·화덕 등 큰 공유 소품은 `chunk_shared_props.glb`의 11개 메시다. 수관은 줄기와 분리해 플레이어 가림을 별도 제어할 수 있다. 모든 장식이 자동으로 충돌 장애물이 되지는 않는다. 별도 충돌이나 수관 투명화는 적용 작업의 대상이다.

## 좌표와 연결

- 청크 한 변은 8 월드 단위다. 모델 원점은 기존 청크의 로컬 타일 (0,0) **중심**과 맞췄다.
- 월드 축 기준 바닥 범위는 X/Y 각각 **-0.5..7.5**다. `(8*chunkX, 8*chunkY)`에 배치하면 인접 바닥이 맞닿는다.
- Blender는 X=월드 X, -Y=월드 Y, Z 위다. GLB는 X=월드 X, +Z=월드 Y, Y 위다.
- 모든 지면 경계의 윗면 높이는 0, 바닥 두께는 0.20이다. 경계 정점 간격은 0.5이며 인접 청크의 외곽 높이를 맞췄다. 내부 다각형 분할은 게임 타일 오브젝트가 아니다.
- 카탈로그의 경로는 **UV 기준**이다. UV (0,0)은 월드 로컬 (-0.5,-0.5), UV (4,4)는 (3.5,3.5)다. 장소의 UV는 전체 16×16 기준이며 `recipe_world_offset`으로 해당 청크를 구분한다.
- 3칸 통로의 중심면은 높이 0으로 비워 뒀다. 바깥 사구·층암은 시각적 높이이며 낙하·층간 전투를 구현하지 않았다.
- 이음 검사는 바닥 형상과 높이 기준이다. 권역 색·식생 전이는 제공한 전이 조합과 주변 모델을 함께 선택해야 한다. 서로 다른 기후를 매 청크 무작위로 바꾸는 용도가 아니다.

주 통행로 예시는 곧은 길·굽은 길·갈림길·빈터 등으로 구성해 모든 청크가 같은 십자 길이 되지 않게 했다. **현재 147칸 성소 격자 도로의 실제 전역 마스크를 자동으로 굽거나 바꾸지는 않았다.** 예시의 통로 중심이 현재 길과 다를 수 있으므로, 다른 적용 작업에서 실제 도로·출입구 마스크와 맞는 모델 선택/변형/통합 베이크를 해야 한다. 보호된 길 위에 나무나 바위를 그대로 얹는 방식으로 적용하면 안 된다.

## 파일

- `world_chunks_v1.blend`: 88개 지면 원본, 공유 소품, 기본/장소 조립 전시, 크기 비교용 주인공
- `world_chunk_library.glb`: 88개 지면 공용 라이브러리. 원점에 겹쳐 있으므로 모델 이름으로 **해당 청크 하나만 선택**한다.
- `CHUNK_*.glb`: 각각 지면 메시 하나만 포함한 개별 전달본
- `chunk_shared_props.glb`: 선택적으로 인스턴싱할 큰 공유 소품
- `chunk_catalog.json`: 문서 ID·변형·모델 키·2×2 장소와 전이 레시피·통로·소품 앵커·보호 영역 규칙
- `source_document_snapshot.md`: 제작 기준 문서 스냅샷
- `validation.json`: 36변형 ID 대응, 88개 8×8 형상·경계, 단일 primitive/COLOR_0, GLB 검수
- `previews/biomes_overview.jpg`, `places_overview.jpg`, `unit_ground_scale.png`: 종류·장소·유닛 크기 비교
- `delivery_files.json`: 최종 파일 SHA256

문서대로 습지↔사막 직접 전이를 만들지 않았으며 허용된 이웃 8쌍만 제공했다. 권역 폭 48~96, 8~16칸 경계, 마을 ±18과 외관 완충 8, 거점 ±12와 완충 4, 튜토리얼 보호, 지역 예산과 고정 장소 ID 규칙은 설계 데이터로 인계한다.

이 작업은 **모델 제작**이다. 지형 스트리밍·매 청크 하나의 드로우 연결·기존 타일 렌더 해제·보호 마스크·NPC 스폰·이벤트·충돌·지형 높이 추적·수영·감속·피해·오염·게임 성능·빌드는 구현/검증하지 않았다. 바닥 렌더를 청크 방식으로 연결하는 작업은 다른 구현 채팅에서 진행한다.

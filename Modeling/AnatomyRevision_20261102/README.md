# 사족 동물 뒷다리·보행 개정

2026-11-02. **AshWolf, BlightBear, ThornStag**의 뒷다리 모델·리깅을 수정하고 기존 **40개 클립 전체**를 새 관절에 맞춰 조정했다. 걷기·달리기는 종별 각각 하나를 유지하며, 방향 회전은 게임 로직에서 처리하는 기존 결정을 따른다.

기존 다리는 대퇴–하퇴–발의 두 긴 구간으로 내려와, 뒤쪽으로 올라가야 할 발목과 긴 발등이 분리되지 않았다. 이번에는 엉덩이 → 앞쪽 무릎(stifle) → 뒤쪽 발목(hock) → 발등(metatarsal) → 발/발굽으로 바꿨다. 무릎을 거꾸로 만드는 방식이 아니다. 종별 관절 구성을 참고한 로우폴리 과장 모델이며 해부학 측정용 실물 복제는 아니다.

| 모델 | 발의 형태 | 수정 내용 | 본 / 클립 |
|---|---|---|---:|
| AshWolf | 발가락으로 딛는 형태 | 올라간 발목, 가는 발등, 굵은 허벅지와 네 발가락·발톱 | 25 / 14 |
| BlightBear | 발바닥 전체로 딛는 형태 | 낮은 뒤꿈치, 긴 발바닥과 다섯 발가락, 무거운 어깨와 보폭 | 26 / 13 |
| ThornStag | 발굽으로 딛는 형태 | 높은 발목, 긴 발등, 네 발의 갈라진 발굽, 도약성 달리기 | 26 / 13 |

참고: [일리노이대 수의학 영상 해부도](https://vetmed.illinois.edu/imaging_anatomy/), [미국 어류·야생동물청의 곰 설명](https://www.fws.gov/species/brown-bear-ursus-arctos-arctos). 곰을 늑대처럼 발뒤꿈치를 높인 체형으로 만들지 않았다.

## 모델과 애니메이션

기존 `hind_l/r_upper`, `hind_l/r_lower`, `hind_l/r_paw` 이름은 유지하고 **hind_l_metatarsal, hind_r_metatarsal** 본을 추가했다. paw의 부모는 새 metatarsal 본이다. 무릎과 발목 위치·다리 실루엣·웨이트·역바인드가 바뀌었다. 기존 몸통·머리·갈기·균낭·뿔은 유지했다.

걷기는 발을 차례로 디디는 보행, 늑대 달리기는 대각 발 짝의 빠른 보행, 곰·사슴 달리기는 체형에 맞춘 네 발의 위상차를 사용한다. 접지 중 발은 뒤로 이동하고 회수 구간에서 들리며, 앞다리가 도달할 수 있는 범위에 맞춰 어깨를 압축한다. 사슴 달리기는 골반을 낮춰 무릎–발목이 곧게 펴지거나 반대로 꺾이지 않도록 했다. 60fps의 본 키프레임이며 재생에 IK 제약이나 물리 계산은 필요 없다.

도약 준비·비행·착지, 곰의 내려찍기와 회복, 사슴 공격·돌진, 대기·피격·사망·등장·특수 이동도 새 뒷다리에 맞춰 재조정했다. 기존 클립 이름·길이·루프 여부·공격/특수 이벤트 시점은 바꾸지 않았다. 발을 정확히 짚기 위한 참조 이동 거리는 `monster_catalog.json`의 `locomotion_reference`에 제공하며, 실제 이동 속도와 재생률의 연결은 적용 작업에서 처리한다.

## 현재 전달 파일

- `../Monsters_v1/monsters_v1.blend`: 개정 원본, 6종 전시와 기존 다른 몬스터 포함
- `../Monsters_v1/AshWolf.glb`, `BlightBear.glb`, `ThornStag.glb`: 교체할 3개 완성 스킨 모델
- `../Monsters_v1/monster_catalog.json`: 갱신 본 계층·클립·보행 참조값
- `validation.json`: 실제 GLB 스키닝·관절·루프·바닥 검사
- `previews/before_after.jpg`: 수정 전/후 측면 비교
- `previews/<model>_Walk.gif`, `<model>_Run.gif`, 특수 행동 GIF: 실제 GLB 재생
- `delivery_files.json`: 현재 전달 파일의 크기와 SHA256
- `backups/`: 수정 전 원본·3개 GLB·카탈로그·검수 보관

**새 GLB의 메시·스킨·본·애니메이션을 통째로 교체한다.** 옛 바인드/스킨이나 뒷다리 애니메이션을 새 메시와 섞으면 안 된다. modelKey·speciesId·MonsterKind·메시 이름은 그대로다. 캐시된 기존 GLB는 적용 작업에서 갱신한다. 다른 몬스터 3종의 GLB와 주인공 기본 모델은 수정하지 않았다.

실제 GLB를 새 장면에 불러와 웨이트 합계, 40개 클립의 길이·키 값·루프, 뒷다리 분절 길이, 무릎이 발목보다 앞에 있는지와 발목 높이를 검사했다. 검수는 표본 프레임 기준이며 모든 실시간 충돌·지형 높이 대응을 구현한 것은 아니다. 게임 코드·빌드·AI·공격 판정은 변경하지 않았다.

# 잿빛 다크 판타지 모델링 키트 v2

2026-10-20. 첨부된 Dark Souls III 이미지의 그을린 철, 오래된 성직 의복, 쇠락한 석조, 잔불의 대비를 참고해 v1의 3등신 로우폴리 모델을 수정했다. 투구와 의복의 구체적 형태·장식은 이 게임용으로 제작했다.

## 외형 변경

NPC와 프롭 전반에 짙은 철회색, 그을린 갈색, 탁한 녹회색, 빛바랜 자주색을 사용했다. 기존보다 어두운 베이스 컬러와 거친 표면, 일부 마모·그을음 재질을 메시 면에 배정했다. 재질 변화는 GLB에도 포함된다. 미리보기 조명에만 의존하는 색 변경이 아니다.

기사 갑옷에 굴곡진 흉갑, 목 보호대, 겹판, 닳은 테두리와 녹슨 고정점을 더했다. 사제복에는 어두운 주름 면과 불규칙한 밑단, 가슴 장식을 추가했다. 건물은 모서리 석재·균열·문틀을 보강했으며, 예배당에는 석조 지지벽을 추가했다. 비석·폐벽에도 작은 파손과 균열을 넣었다.

로우폴리 플랫 셰이딩과 머리 약 0.6m/기본 신장 1.8m의 3등신 규격을 유지한다. 머리 장비는 기본 키보다 돌출되며 사제관의 최고점은 약 2.12m다. 단색 PBR 재질과 면별 색 차이를 사용하며 외부 텍스처·UV 아틀라스·프로시저럴 셰이더에 의존하지 않는다. 실시간 엔진에서는 해당 엔진의 조명과 재질 처리에 따라 밝기가 달라진다.

## 머리 장비와 인덱스

v1의 슬롯 0–19와 기존 파트 이름·인덱스는 유지했다. **배열 끝에 슬롯 20 `headgear`를 추가**했으므로 `part_indices` 길이는 20에서 21로 늘었다. 빈 슬롯은 -1이다.

| 장비 인덱스 | 메시 | 형태 |
|---:|---|---|
| 0 | `NPC_HEADGEAR_00_AshKnightClosed` | 눈 틈·통풍구·목 보호대가 있는 폐쇄형 기사 투구 |
| 1 | `NPC_HEADGEAR_01_WardenOpenHelm` | 얼굴이 드러나는 개방형 투구 |
| 2 | `NPC_HEADGEAR_02_CinderClericMitre` | 이중 봉우리 사제관과 뒤쪽 띠 |
| 3 | `NPC_HEADGEAR_03_PilgrimHood` | 두꺼운 테두리의 순례자 후드 |
| 4 | `NPC_HEADGEAR_04_RaggedHood` | 자주색의 해진 후드 |
| 5 | `NPC_HEADGEAR_05_WayfarerCap` | 낮은 챙과 버클을 가진 상인 모자 |

모든 장비는 남녀 공용이다. **6개 장비 모두 착용 시 hair 슬롯 1을 -1로 비운다.** 폐쇄형 투구 0은 **head 슬롯 0도 -1**로 비운다. 모자·후드 속 머리카락과 얼굴이 장비를 뚫지 않도록 기본 프리셋에 반영한 규칙이다.

`sex_index`, `hair_style_index`는 장비를 착용해도 보존한다. 장비를 벗을 때 head 슬롯에 `sex_index`, hair 슬롯에 `hair_style_index`, headgear 슬롯에 -1을 다시 선택하면 된다. 머리카락을 가리는 장비를 착용한 동안에는 짧은머리/긴머리 외형 차이가 보이지 않으며, 폐쇄형 투구를 쓰면 얼굴의 성별 차이도 가려진다.

장비 규칙은 원본과 GLB extras의 `hides_hair`, `hides_head`, 그리고 JSON의 `headgear_rules`에 기록했다. 이 속성은 적용 작업에서 읽기 위한 데이터이며 자동으로 메시를 숨기는 게임 기능은 아직 없다.

## 조립과 프리셋

모든 NPC 파트의 공통 원점은 발바닥 중앙이다. 정점에 기본 자세 위치가 들어 있으므로 조립 시 로컬 이동·회전을 0, 스케일을 1로 둔다. 관절 위치 `joint_pivot`을 메시 이동값으로 적용하지 않는다. Blender는 Z 위·정면 -Y, GLB는 Y 위·정면 +Z이며 JSON에 양쪽 관절 좌표를 제공한다.

슬롯 순서: 0 head, 1 hair, 2 torso, 3–4 upper_arm_l/r, 5–6 forearm_l/r, 7–8 hand_l/r, 9 pelvis, 10–11 thigh_l/r, 12–13 shin_l/r, 14–15 foot_l/r, 16 skirt, 17 accessory_back, 18 accessory_waist, 19 accessory_hand, **20 headgear**. 기존 슬롯별 파트 선택값은 v1 규격과 같다. 사제복 하단 사용 시 pelvis·thigh_l/r·shin_l/r는 -1로 비운다.

카탈로그의 프리셋은 장비 착용 20개와 미착용 20개로 총 40개다. 착용 프리셋 ID에는 `_GEAR0`처럼 장비 번호가 붙는다. 이는 조립 데이터의 수이며 40벌의 별도 메시를 만든 것이 아니다. 장비 착용 GLB 프리뷰는 20개만 배치했다.

직군 인덱스는 0 Priest, 1 Knight, 2 Adventurer, 3 Raider, 4 Merchant다. 프리뷰의 열도 이 순서이며, 각 열의 앞쪽부터 남/짧은 헤어 정체성, 남/긴 헤어 정체성, 여/짧은 헤어 정체성, 여/긴 헤어 정체성 순서다. 성직자는 사제관/후드, 기사는 폐쇄형/개방형 투구를 번갈아 보여 준다.

주민 외형 JSON은 v1의 336명 ID·이름·직군·성별·헤어 배정을 보존하고 머리 장비와 21개 파트 배열을 갱신했다. 성별·헤어는 모델링 외형 제안이며 게임에서 확정된 설정은 아니다. 게임 소스의 인구나 ID 생성 규칙이 바뀌면 적용 시 대응을 다시 확인한다.

## 원본 구성과 검수 범위

`NPC_PART_LIBRARY`와 `PROP_LIBRARY`는 원점에 겹쳐 놓고 숨긴 원본이다. 필요한 파트만 표시해 편집한다. `NPC_ASSEMBLY_PREVIEW`·`PROP_PREVIEW`·`HERO_LINEUP`은 원본 메시를 공유하는 전시용 복제다. `PRESENTATION`과 DISPLAY 오브젝트는 전달용 모델이 아니다.

프롭 인덱스 0–13과 이름은 v1을 유지한다. 불꽃은 정적 발광 메시이며 파티클·실제 광원·동적 불꽃은 포함하지 않는다. 건물은 외관용이며 실내나 움직이는 문은 없다. 본·스킨 웨이트·애니메이션·충돌체·LOD도 미포함이다.

NPC 조합과 대표 모델, 프롭을 실제 Blender 렌더로 확인했다. 기존 인덱스 보존, 21슬롯 참조, 머리 장비와 머리카락 배제, NPC ID 중복, GLB 라이브러리 이름·원점 검사를 수행했다. 정적 기본 자세에서의 확인이며 모든 임의 조합·애니메이션 포즈와 게임 엔진 성능을 검증한 것은 아니다.

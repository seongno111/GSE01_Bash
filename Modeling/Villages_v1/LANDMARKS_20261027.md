# 메인 건물 랜드마크 개정

2026-10-27. 마을의 메인 건물이 일반 주택과 혼동되던 문제를 해결하기 위해 **6개 CHAPEL 모델을 실제 새 형상으로 교체**했다. 탑의 수와 비율, 건물의 단차, 입구와 지붕, 멀리서 보이는 상징물을 마을마다 다르게 설계했다. 기존 로우폴리 다크 판타지의 무광 석재, 검게 산화한 금속, 낡은 목재와 바랜 천을 공유한다.

| 마을 | 메인 건물 | 멀리서 읽히는 형태 | 가까이 보이는 요소 |
|---|---|---|---|
| 성당 마을 | 쌍탑 구호 대성당 | 높이가 다른 두 첨탑, 십자형 신랑 | 장미창, 첨두 출입구, 공중 부벽, 성인상, 후진 |
| 새벽 수도촌 | 태양 첨탑 수도원 | 긴 팔각 첨탑과 커다란 태양 후광 | 금속 지붕 리브, 황금빛 창, 부벽, 양측 회랑 |
| 철벽 주둔촌 | 철벽 지휘 요새 | 높은 중앙 성채와 네 방어탑 | 여장, 철창문, 층별 돌림띠, 검과 방패 문장, 군기 |
| 황금 장터 | 황금 저울 상인회관 | 시계탑, 층층이 벌어지는 지붕, 저울 풍향계 | 시침·분침·시간 눈금, 발코니, 목재 가새, 차양, 상단 기 |

새 건물은 약 2,284–4,008삼각형으로, 기존 일반 건물보다 실루엣과 입체 디테일에 폴리곤을 집중했다. 텍스처 없이 OPAQUE PBR 재질을 사용한다. 장미창·눈구멍·창은 벽 앞의 입체 인셋이며 실내를 구현한 모델은 아니다. 지붕과 구성 요소는 각각 닫힌 입체로 만들었고, 관측소의 천구 고리 아래에도 닫힌 지붕이 있다. 여러 입체가 교차하는 조립형 정적 메시이며 전체를 불리언으로 합친 단일 수밀 솔리드는 아니다.

## 전달 파일과 안정적인 선택 키

기존 파일을 갱신했다. 별도 팩을 추가 로드할 필요 없이 아래 이름을 그대로 선택할 수 있다.

| village_id | 변경한 기존 modelKey | 현재 크기 계산을 적용한 높이 |
|---|---|---:|
| cathedral | VIL_CATHEDRAL_CHAPEL | 약 6.06m |
| dawn | VIL_DAWN_CHAPEL | 약 6.98m |
| iron | VIL_IRON_CHAPEL | 약 6.37m |
| market | VIL_MARKET_CHAPEL | 약 7.55m |
| seekers | VIL_SEEKERS_CHAPEL | 약 6.48m |
| outlaws | VIL_OUTLAWS_CHAPEL | 약 6.50m |

높이는 현재 `ModelVillageBuildings.cpp`가 사용하는 지면 최대 절댓값 2.15 기준의 균일 축소를 실제 내보낸 형상에 적용해 계산했다. 출입구 높이도 같은 축소 뒤 약 1.84–1.93m가 되도록 맞췄다. 일반 주택도 같은 로더의 주택 기준 1.65로 줄여 나란히 렌더했다. 원본 마을 배치 전시와 게임 크기 비교 전시는 목적이 다르므로 해당 미리보기 제목을 구분한다. 이는 Blender에서의 크기 비교이며 실제 게임 실행 결과는 아니다.

- `villages_v1.blend`: 36개 원본과 링크된 마을·상세·크기 비교 전시
- `village_buildings.glb`: 기존과 같은 36개 정적 메시, 이 중 메인 건물 6개 교체
- `cathedral.glb`, `dawn.glb`, `iron.glb`, `market.glb`, `seekers.glb`, `outlaws.glb`: 각각 같은 테마의 6개 메시
- `village_catalog.json`: 스키마 1·기존 키를 유지하고 치수, 삼각형 수, 랜드마크명, 상징 요소, 크기 참고값 추가
- `validation.json`: 형상 검수 결과
- `landmark_delivery.json`: 최종 원본·전달 GLB·카탈로그의 크기와 SHA256
- `previews/landmarks_overview.jpg`: 6종 상세 비교
- `previews/landmarks_scale_comparison.jpg`: 현재 크기 기준 주택 비교
- `previews/themes_overview.jpg`: 마을에 배치한 새 랜드마크 비교

모든 전달 메시의 원점은 기존 바닥 중심이다. Blender는 Z 위·정면 -Y, GLB는 Y 위·정면 +Z, 미터 단위다. 출입구도 기존 정면을 유지했다. 각 건물은 하나의 메시이므로 기존 로더의 단일 노드 선택과 맞는다. 원본에는 `RoseWindowTracery`, `FlyingButtressArms`, `GreatMeridianRing`, `GreatCurvedTusks` 등의 이름 있는 버텍스 그룹을 넣어 세부 형상을 고르기 쉽게 했다.

## 검수와 적용 범위

원본과 내보낸 GLB를 모두 검사한다. 새 구성 입체의 경계 폐쇄, 유한 정점·단위 법선·면적이 있는 삼각형·법선 방향, 좌표 변환 후 치수 일치, 카탈로그 대응, 7개 GLB의 모델 수를 확인한다. 기존 일반 건물 30개는 교체 전 GLB와 삼각형 위치 및 재질 이름으로 비교한다. 검수 결과는 `validation.json`의 모든 check가 true인지 확인하면 된다.

기존 `village_id + kind 5` 매핑과 36개 모델 수를 유지했다. 다른 30개 메시, NPC·몬스터·주인공, 게임 코드·월드 배치·충돌체·빌드는 수정하지 않았다. 게임 폴더에 복사된 이전 모델이나 실행 중 캐시는 별도 적용 작업에서 최신 파일로 갱신한다. 새 시각적 외형에 맞춘 충돌체도 별도 적용 대상이다.

교체 전 상태는 `revisions/20261027_before_landmarks/`에 보관했다. 이전 2026-10-26 인계 폴더의 해시는 당시 전달본을 기록한 것이므로 이번 수정본의 해시는 `landmark_delivery.json`을 사용한다.

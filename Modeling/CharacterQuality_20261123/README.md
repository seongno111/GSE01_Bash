# NPC·몬스터 체형과 모델 품질 개정

2026-11-23. 주인공의 5등신 체형과 로우폴리 디테일에 맞춰 NPC 공용 파트 51개, 직군 5종, 몬스터 11종을 개정했다. 인간형은 머리를 줄이고 몸통과 팔다리를 재조정했다. 동물형은 종별 체형과 기존 사족 관절을 살려 형상을 보강했다.

[주인공·NPC 비교](previews/npc_lineup.jpg) · [몬스터 11종](previews/monster_lineup.jpg)

NPC는 머리 높이 약 0.365m, 신장 1.84m로 약 5.04등신이다. 조립한 모델의 삼각형 수는 성직자 3,752개, 기사 6,108개, 모험가 5,219개, 약탈자 4,889개, 상인 4,496개다. 의복의 굴곡과 띠 장식, 겹판 갑옷, 장갑과 손가락, 장화와 밑창을 형상으로 만들었다. 머리·머리카락·투구·모자·후드도 새 머리 크기에 맞췄다.

몬스터는 모델당 약 5,200~12,700삼각형이다. 망자의 갈비뼈와 발톱, 약탈자·수문장·성기사의 갑옷 겹판, 변이체와 아자르의 어깨 돌기·흉부 형상, 사제의 의복 테두리를 보강했다. 늑대의 목덜미 털과 주둥이, 곰의 털·균낭, 사슴의 발굽과 가지 뿔을 다듬었다.

공용 NPC 파트와 몬스터의 메시 이름, 21개 슬롯 순서, 파트 인덱스, 조합 프리셋 40개, 주민 336명의 외형 할당은 기존 규격을 따른다. 투구 안에는 선택한 남녀 머리를 함께 사용한다. 남녀·짧은 머리·긴 머리·직군 조합은 같은 파트 라이브러리로 조립한다.

인간형 135개 동작을 개정한 바인드와 다리 길이에 맞춰 다시 구웠다. 사족 3종의 40개 동작과 발목·발등 관절은 기존 개정본을 따른다. NPC 39개, 기존 몬스터 49개, 추가 몬스터 87개를 합쳐 고유 동작은 175개다. 클립 이름·길이·루프·타격 및 발사 이벤트 시점을 대조했다. 표준 걷기와 달리기는 각 리그에 하나씩이며, 방향 회전은 Actor에서 적용하는 기존 규약을 따른다.

인간형의 바인드 좌표와 역바인드가 바뀌었으므로 **모델·스킨·본·애니메이션을 함께 교체한다.** 파트별 메시만 따로 가져올 때도 새 공용 NPC 리그에 결합한다. 이전 파일은 이 폴더의 `backups/`에 보관했다.

[바이너리 검수](validation.json)에서 17개 GLB의 이름·본·스킨·웨이트·유한 키 값·루프·클립과 파트 정보를 검사했다. [재생 검수](playback_validation.json)는 GLB를 새 Blender 장면으로 가져와 각 동작의 시작·끝과 7개 중간 위상에서 실제 변형을 확인한 결과다. 검사한 자세에서 바닥 관통은 2mm 허용 범위 안이고, 팔다리 본 연결 오차는 1mm 이내였다. 임의의 의상 조합 전체나 게임 안의 충돌·속도·블렌딩은 이 검사 범위에 포함되지 않는다.

`delivery_files.json`은 교체 파일과 검수·미리보기의 SHA256 목록이다. `scripts/`에는 형상 제작, 바인드 조정과 키프레임 베이크, 내보내기, 렌더와 검수에 사용한 Blender/Python 스크립트를 포함했다. 게임 적용과 빌드는 별도 작업이다.

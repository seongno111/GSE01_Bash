## 원점과 장착

각 무기는 **손잡이 기준 원점 (0,0,0)**이며 루트 오브젝트도 같은 키다. 루트 아래의 `__Body` 메시를 포함해 무기 전체를 하나의 장착 단위로 사용한다. 활은 `__String`을 별도 메시로 두어 나중에 시위를 당길 수 있게 했다. 지팡이에는 `__Cast`, 활에는 `__Nock` 위치를 제공한다. 메시 수는 무기·화살 전체 합계 9개다.

Blender는 Z 위·무기 길이 +Z, GLB는 Y 위·무기 길이 +Y다. 활/화살의 발사 정면은 Blender -Y, GLB +Z다. 화살은 꼬리/nock가 원점이며 촉이 발사 정면에 있다. 단위는 미터다.

현재 주인공의 `weapon_r` / `weapon_l` 노드에 장착할 수 있도록 **실제 Hero GLB의 정적 관절 회전**에서 역회전을 구해 `hero_rest_mounts_gltf`에 넣었다. translation 0, scale 1과 quaternion xyzw/열 우선 4×4 행렬을 제공한다. 손 본은 무기축과 다르므로 무기 루트에 아무 회전도 주지 않고 붙이면 축이 틀어질 수 있다. 부모 관절 변환 × 제공 장착 변환 × 무기 루트 순으로 사용한다. 현재 Hero GLB의 SHA256도 기록해 다른 리그에 숫자를 그대로 적용하는 것을 피한다.

활은 왼손을 사용하므로 장착 시 기존 램프 프레임·불꽃과 램프 광원을 숨기는 선택이 필요하다. 기존 기본 검을 바꿀 때는 검신·손잡이 둘을 함께 교체한다. 이는 후속 장비 로직에서 처리할 내용이며 이 팩은 주인공의 기본 장비를 변경하지 않는다.

교체 기능·무기별 공격/조준/장전 동작·피해·탄체·활 시위 변형 로직은 아직 포함하지 않았다. 새 모델의 그립과 분리 파트를 준비한 상태다. 기존 NPC 파트 인덱스나 게임의 무기 enum 숫자를 재사용하지 않으며, 식별은 weapon_key 문자열로 한다.

`validation.json`에 개별/전체 GLB의 파트·루트·원점·정적 OPAQUE 재질·유한 정점·실제 Hero 장착 축 검사를 기록했다. `delivery_files.json`은 최종 파일 SHA256이다. 게임 코드·빌드는 수정하지 않았다.

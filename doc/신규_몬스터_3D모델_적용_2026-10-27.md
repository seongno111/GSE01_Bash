# 신규 몬스터 6종 3D 모델 적용

2026-10-27. `Modeling/Monsters_v1/README.md`, `monster_catalog.json`, `validation.json`과 기존 몬스터 정의·행동 코드를 기준으로 연결했다. Blender 원본과 제작 카탈로그는 수정하지 않았다.

## 모델 연결

`ModelLibrary::MonsterSpecies(modelKey)`로 별도 등록한다. `MonsterKind` 3~8을 기존 `Monster(int)`에 넘기지 않는다. 기존 인덱스 3의 변이 인간과 4의 죽음 잔재는 기존 모델을 사용한다.

카탈로그의 모든 메시 노드를 선택해 몸체 외의 균낭·뿔·날개·불씨·방패·검·지팡이·도구도 함께 그린다. GLB의 미터 단위 크기를 월드 스케일 1로 적용하고 별도 높이 배율을 곱하지 않는다. 이름과 체력바는 기존 기준 높이와 모델 높이 중 큰 값을 사용한다. 기존 피격 반경·길 찾기·스폰 위치·능력치는 유지한다.

## 애니메이션 연결

- 배회·추격·측면 이동·후퇴·복귀: 카탈로그의 해당 상태 클립을 선택한다. 늑대의 좌우 측면 이동은 개체의 기존 협공 방향에 맞춰 나눈다. 이동 위상은 기존 충돌 후 이동량을 누적한 부드러운 보행 위상을 사용한다.
- 기본 공격: Bite, Swipe, Gore, Volley, Slash, Curse 전체 클립을 AI의 준비·회복 타이머에 맞춰 재생한다.
- 늑대·사슴: Prepare → 제자리 Travel 반복 → Land/Stop을 사용한다. 실제 위치와 충돌·명중은 기존 AI가 처리한다.
- 곰·아자르·사제: Slam/Rift/Mend 전체 클립을 사용한다. 단계별 클립을 동시에 재생하지 않는다.
- 성기사: 0.6초 준비 → 2.4초 방벽 유지 → 해제를 연결한다. 방벽의 짧은 AI 회복 0.25초를 방벽 전체 지속 시간으로 해석하지 않는다. 방벽 중 기본 공격을 하면 공격 클립을 우선한다.
- AI 갱신 사이 최대 0.05초는 화면의 타이머만 보간한다. 피해·발사·회복을 미리 처리하거나 중복 처리하지 않는다.
- 단발 클립 전환은 이전 동작의 재생 위상을 이어받지 않고 시작하며, 기존 0.12초 포즈 혼합을 사용한다. 이동 좌우 방향은 기존 모델 yaw 회전을 사용한다.

123개 클립을 모두 로드·검사하지만 현재 AI에서 발생하는 위 상태들에 연결한다. Turn, Hit, Spawn, Death/DeadHold와 별도의 Enrage/Roar 연출은 이번에 새로운 AI 상태나 사체 표시 기능으로 추가하지 않았다. 기존 광폭화 색 변화와 공격 예고 지면 표시는 유지한다.

## 자원·로그·오류 처리

종별 GLB는 초기화 시 한 번 읽고 CPU/GPU 메시와 선택 인덱스 버퍼를 공유한다. 개체별로 포즈·애니메이션 시간만 다르며 매 프레임 파일을 읽거나 메시를 새로 만들지 않는다. 여러 부착 메시도 기존 렌더러에서 하나의 선택 인덱스로 그린다. 종별 모델은 그림자·경고 표시를 제외한 본체 기준 1 드로우다. 실제 프레임 성능은 측정하지 않았다.

로더는 종 ID·modelKey·파일명·모든 메시·클립 길이·이벤트 범위·기본/특수 공격 시간·삼각형 수·제작 검수 결과를 검사하고 6종이 완전할 때 등록한다. 실패하면 `[ModelAssets] monster species unavailable: ...`에 원인을 기록하고 기존 도형 표시를 사용한다.

정상 로딩 로그:

```text
[MonsterModels] species=ash_wolf model=AshWolf meshes=1 clips=20 triangles=1035 height=... scale=1
[MonsterModels] ready species=6 clips=123 legacyIndicesUnchanged=1
```

## 수정 파일과 확인

- `SimpleGame/ModelMonsterSpecies.cpp`, `ModelLibrary.h/.cpp`: 별도 종별 팩 로딩·검사·조회.
- `SimpleGame/MonsterModelVisuals.cpp`: AI 상태별 모델 클립 선택·재생 위치.
- `GameActors.h`, `MonsterBehavior.cpp`: 기본/특수 회복 구분과 시각 타이머 기록.
- `EnemyActor.cpp`, `Prototype.h`, `MonsterVisuals.cpp`: 3D 표시 우선, 지면 경고 공용화, 체력바 높이.
- `ModelActorVisuals.cpp`: 단발 클립 시작 위상 처리.
- `SimpleGame.vcxproj`와 filters: 새 소스 등록 및 `monster_catalog.json` 배포.

`doc/tools/inspect_monster_models.py`로 6개 실제 GLB의 스킨·정점 웨이트·역바인드·123개 클립·루프·관절 키 변화·메시 부착·미터 높이·공격 이벤트와 AI 시간·프로젝트 등록을 읽기 전용으로 검사했다. 정적인 DeadHold는 관절 움직임 검사에서 제외한다. 결과는 `몬스터_모델_정적검토_2026-10-27.json`에 기록했다.

# 성당 마을 NPC AI 프로토타입

작성일: 2026-09-29

2026-10-13 후속 변경: 현재 주민 배치·경제·원거리 갱신·경로 범위는 [다중 마을 구현 기록](NPC_AI_다중마을_구현.md)이 우선한다. 아래 내용은 초기 단일 마을 구현 기록이다.

활동 동선·성역 상태 전환·직업별 공격의 후속 변경은 [NPC 활동성 개선](NPC_AI_활동성_개선.md)을 참고한다. 아래 초기 구현 수치와 충돌하는 경우 후속 문서가 최신이다.

기준 문서: `NPC_AI_행동_설계.md`. 원본 설계서는 수정하지 않았다. 이번 구현은 기존 오픈월드에 마을과 일반 주민의 실시간 행동을 연결하는 첫 프로토타입이다. 설계서의 장기 기능 전체가 완성된 상태는 아니다.

## 월드와 주민

기존 청크 스트리밍과 경작지 규모를 유지한다. 시작 지점 서쪽의 x=-10~3, y=-6~10에 성당, 성소, 시장, 숙소·작업장, 훈련장을 배치한다. 마을 바닥은 통행 가능한 길로 만들고 건물에는 기존 정적 충돌체계를 적용한다. NPC 이동은 몸체 반경을 고려한 직선 경로와 격자 우회 경로를 사용한다. 실제 렌더링과 모든 시드의 통행성 확인은 아직 수행하지 않았다.

주민은 SceneGraph의 `VillageResidents` 아래에 NpcActor로 생성된다. 역할별 외형은 기존 Renderer의 디스크 메시 캐시와 배칭 경로를 사용한다.

| 주민 | 직업 | 주된 목표 |
| --- | --- | --- |
| 엘라 | 성직자 | 신앙 |
| 루카 | 성직자 | 건강 |
| 가렌 | 기사 | 무력 |
| 테오 | 기사 | 신앙 |
| 리나 | 모험가 | 깨달음 |
| 도란 | 모험가 | 자산 |
| 미르 | 모험가 | 건강, 초기 부상·오염 |

| 에다 | 상인 | 깨달음 |
| 칼로 | 약탈자 | 자산, 약탈 가중치 0.95 |

일반 주민에게 설계서의 주요 서사 인물 이름을 부여하지 않았다. 주민 사망은 현재 세션에서 영구적이며 플레이어처럼 부활하지 않는다.

## 행동과 실제 상태 변화

- 성직자는 부상자를 치료하거나 축복하고 기도한다. 축복에는 성력 8, 치료에는 약품 1개가 필요하다.
- 기사와 모험가는 순찰·토벌·훈련에 참여한다. NPC가 괴물을 처치하면 해당 NPC의 전리품과 무력이 증가한다. 플레이어에게 처치 경험치를 중복 지급하지 않는다.
- 약탈자는 목격한 인간을 대상으로 공격과 금화 강탈을 선택한다. 성공한 약탈은 피해자의 실제 금화에서 최대 12개를 이전한다.
- 거래·노동은 주민 자산과 마을의 실제 재고·금고를 변경한다. 초기 금고 600, 식량 60, 약품 30으로 시작한다. 노동은 금고에서 임금 5를 지급하고 생산한다. 전리품 판매는 8, 식량 구매는 6, 약품 구매는 12이다. 자원이 부족하면 행동이 거절될 수 있다.
- 휴식과 식사는 체력·피로·허기를 회복한다. 기도는 성력, 훈련은 무력·최대 체력, 성찰은 지혜를 높인다.
- 마을 밖의 활동 중 오염이 누적되며 성력·지혜가 누적 속도를 줄인다. 실제 오염 85 이상과 오염 가중치 0.8 이상이 함께 충족되면 광폭화하여 주변 인간에게도 적대한다. 다른 NPC는 상대의 숨겨진 오염 수치를 읽어 적대하지 않는다.
- 오염 100 미만은 성소 정화로 금화 3을 기부하고 30을 줄인다. 100 이상은 DawnOil 특별 아이템을 사용하는 행동만으로 되돌린다. 현재 초기 주민은 이 아이템을 갖고 있지 않으며 NPC의 아이템 획득 경로는 후속 작업이다.
- 정화는 원한을 초기화하지 않는다. 실제 피해와 범죄 목격으로 형성된 관계는 별도로 유지한다.

## 판단과 실행 규칙

19개 행동 유형마다 대표 대상을 하나 정하고 자격부터 검사한다. 체력·재고·직업·현재 모드·관측 정보·예약·쿨다운·경로가 조건이다. 대상 수가 많다는 이유만으로 특정 행동의 선택 확률이 높아지지 않게 한다.

점수는 `clamp(기본 + 성격 + 욕구 + 관계 + 상황 + 목표 - 비용, 0, 100)`에 지속성과 반복 억제를 곱한다. 최근 30초 이내의 완료 행동 중 최근 3개를 반복 평가에 사용한다. 허용된 가중치를 최댓값으로 정규화한 뒤 온도에 따른 거듭제곱을 적용한다. 행동 ID 순으로 정렬하고 NPC별 난수열에서 한 번 추첨한다. 시작 실패 시 결정적인 대안 한 번과 안전한 대기만 사용한다.

실행은 준비 → 접근 → 수행 → 회복 → 완료 단계다. 공격 준비 중 일반 대화 요청으로 공격을 취소할 수 없다. 효과 직전에 생존·거리·시야·자원 등을 다시 검사하고 실행별 적용 표시로 중복 지불·중복 피해를 막는다. 효과 적용 시 쿨다운을 시작한다. 실패한 행동과 대상 조합은 3초 동안 억제한다. 치료 대상과 공용 시설에는 최대 18초의 예약을 걸고 완료·실패·사망 시 해제한다. 행동 전체 제한은 15초다.

관측은 거리 8과 장애물 시야 검사에 의존한다. 대상 위치와 관측 시각을 저장하고 30초가 지나면 잊는다. 접근 중에는 마지막 관측 위치를 사용하며 3초 넘게 놓친 대상은 취소한다. 시야 밖의 최신 좌표나 타인의 자산·오염 수치를 판단에 사용하지 않는다.

## PK와 안전 구역

J로 PK를 켜면 성역 밖의 중립 주민도 기존 자동 조준 대상에 포함된다. C는 상태창의 주민 선택이며 공격 대상 고정 기능은 아니다. PK를 꺼도 이미 발생한 원한은 사라지지 않는다. 공격당한 주민과 범죄를 직접 목격한 기사·성직자가 관계를 갱신한다. 성직자의 대응은 역할 규칙에 따라 치료·회피 등에 머물 수 있다.

성역 안은 피해와 약탈을 차단한다. 마을 전체가 안전 구역인 것은 아니다. 기본 PK는 꺼져 있어도 적대 주민과 광폭화 주민은 공격 대상이다. 플레이어가 주민을 처치하면 남은 금화를 획득한다. 기존 플레이어 죽음·오염·변이 잔재 시스템은 유지한다.

## 조작

| 키 | 기능 |
| --- | --- |
| C | 가까운 주민을 차례로 상태창에 선택 |
| I | NPC 상태·판단 확률 창 표시 전환 |
| J | 중립 주민에 대한 PK 전환 |
| E | 성역 밖에서 선택 주민에게 대화 요청, 성역에서는 기존 상호작용 |
| Y | 선택 주민에게 회복약 구매 요청: 마을 내, 금화 12, 시장 재고 필요 |
| O | 선택 성직자에게 축복 요청: 성력 8 필요 |
| L | NPC 진단 로그 즉시 저장 |

요청에는 거리 2.2 이내와 시야가 필요하다. 적대·전투 중이거나 이미 처리 중인 요청이 있으면 거절한다. 성공한 요청은 보통의 일상 행동보다 우선한다. 대사와 거절 사유는 한국어다. 현재 대화는 상태에 따른 로컬 문장이며 외부 생성형 AI 연결은 포함하지 않는다.

## 시간·성능·진단

NPC 상태와 이동은 0.05초 고정 간격으로 갱신한다. 관측은 평시 0.8초, 전투 0.3초 간격이며 초기 시간을 분산한다. 의사결정은 행동 실행과 모드 변경에 따라 예약하고 매 렌더 프레임마다 추첨하지 않는다. 거리 40 밖의 유휴 NPC는 회복 등 요약 갱신을 사용하고, 보이지 않는 곳의 무작위 사망·약탈·보상을 만들어내지 않는다. 진행 중인 행동은 완료 절차를 유지한다.

우회 탐색 격자는 초기 지역 x=-12~24, y=-8~15로 제한한다. 무한 청크에 걸친 주민 이동과 인구 스트리밍은 아직 지원하지 않는다. 직접 통행 가능성 검사와 후보별 경로 검사 비용은 향후 실측이 필요하다. 기존 프레임 프로파일의 업데이트 시간에는 NPC 갱신도 포함된다.

실행 파일 옆 `NpcAI/latest.log`를 시뮬레이션 시간 10초마다, 또는 L키로 갱신한다. 임시 파일에 쓴 뒤 교체한다. 최근 512개 판단·사건 기록과 현재 주민 상태를 보관하며 이전 스냅샷은 덮어쓴다. 장시간 이력을 보존하려면 해당 파일을 별도로 복사해야 한다.

판단 기록에는 시드, NPC ID, 순번, 난수 상태·추첨값, 모드, 선택 행동·대상·실행 ID, 요청 여부가 있다. 후보별 `allowed/reason`으로 제외 이유를, `B/P/N/R/S/G/C`로 점수 항을, `continuity/repeat/W/probability`로 최종 선택 근거를 확인한다. 주민 상태에는 체력·자산·성력·무력·지혜·오염·관측 기억·원한·쿨다운·실행 단계·예약을 기록한다.

환경 변수 `EMBER_WORLD_SEED`에 정수를 지정하면 초기 월드와 NPC 난수 시드를 고정할 수 있다. 전체 게임은 입력·다른 Actor 갱신 시점에도 영향을 받으므로 완전한 리플레이 재현을 보장하지 않는다. 로그는 로딩 가능한 저장 파일이 아니다.

## 코드 위치

- `NpcAI.h`, `NpcBrain.cpp`: 상태 모델, 행동 점수, 확률 선택.
- `NpcWorld.h/.cpp`: 주민 생성, 관측, 후보 구성, 예약, 시뮬레이션, 로그.
- `NpcActions.cpp`: 경로, 단계별 실행, 경제·전투 효과, 목격·원한.
- `NpcActor.cpp`: SceneGraph Actor, 캐시 메시와 이름·체력 표시.
- `NpcInterface.cpp`: 한국어 상호작용과 디버그 상태창.
- `World.cpp`, `ActorVisuals.cpp`: 마을 배치와 건물 표현.

주민 초기 특성과 주요 시설 위치는 `NpcWorld.cpp`, 점수 계수는 `NpcBrain.cpp`에서 조정한다. 별도의 JSON 데이터 로더는 아직 없다.

## 후속 범위와 사용자 확인 항목

완전한 저장·복원, JSON 행동 데이터, 외부 대화 AI, 주요 서사 인물·퀘스트, 구조·호위·집단 지휘, 여러 마을의 인구 스트리밍은 후속 구현이다. 기존 보스와 변이 잔재의 AI 전체를 이 체계로 교체하지 않았다.

빌드·게임 실행·렌더링 결과 검증은 사용자 요청에 따라 수행하지 않았다. 다음 순서로 실행 확인을 권장한다.

1. 마을 건물과 경작지 연결, 생성 시 주민이 건물 안에 끼지 않는지 확인한다.
2. C/I로 여러 직업의 체력·자산·성력·무력과 선택 확률 변화를 관찰한다.
3. 주민 곁에서 Y/O/E를 사용해 자원 소모와 한국어 응답, 거리·재고 부족 거절을 확인한다.
4. J를 켜 성역 밖에서 주민을 공격한 뒤 피해자와 목격한 기사의 대응을 확인한다. J를 꺼도 원한이 유지되어야 한다.
5. 약탈과 광폭화 주민의 전투, 성역 보호, 일반 주민의 사망을 확인한다.
6. L을 눌러 실행 파일 옆 로그에서 자격 제외 이유와 실제 자원 이전 기록을 확인한다.
7. 기존 자동 사격·아이템·죽음의 오염·변이 잔재·보스와 프레임 프로파일에 회귀 문제가 없는지 확인한다.

## 로더와 배포

- `SimpleGame/ModelVillageBuildings.cpp`: 중심 건물 키 대응을 확인하고 실제 메시의 축소율·높이·삼각형 수를 카탈로그와 비교한다. 새 필드가 없는 이전 카탈로그도 지원한다. 로딩 시 `[VillageLandmark]`에 마을·개정판·모델·축소율·높이·삼각형 수를 기록한다.
- `SimpleGame/SimpleGame.vcxproj`: 기존 GLB/카탈로그 배포에 `landmark_delivery.json`을 포함했다.
- 기존 `x64/Debug/Modeling/Villages_v1`, `x64/Release/Modeling/Villages_v1`에 GLB 7개, 카탈로그·검수 JSON 2개, 배포 명세 1개를 복사했다. 실행 파일을 빌드하거나 실행하지 않았다.
- 메모리와 GPU에 올라간 모델은 캐시되므로 실행 중인 게임은 종료 후 다시 실행해야 새 파일을 읽는다.

공용 `village_buildings.glb` 하나에서 건물별 노드를 선택하는 방식이다. 각 중심 건물은 계속 1개 메시이며 기존 렌더러의 정적 버퍼·선택 인덱스 캐시를 사용한다. 이번 교체로 모델 수와 건물당 드로우 횟수는 늘어나지 않지만, 삼각형 증가에 따른 실제 GPU 비용은 측정하지 않았다.

# 마을 규모·전서구 통신·주민 이사 확장

작성일: 2026-10-20

## 적용 규모

| 항목 | 기존 | 변경 |
|---|---|---|
| 마을 수 | 6개 | 6개 |
| 마을 이름·문화 | 자비, 신앙, 규율, 교역, 탐구, 약탈 | 기존 6개 문화 및 초기 직군 비율 유지 |
| 마을 생활권 | 중심 기준 x=-10~3, y=-6~10 | x=-18~18, y=-18~18 |

| 인접 마을 중심 간격 | 32칸 | 147칸 |

마을 하나의 연속 좌표 기준 면적은 1296칸²이다. 기존 마을 하나의 208칸² 대비 약 6.23배, 기존 6개 마을 생활권 면적을 합한 값보다 약 3.85% 넓다. 여러 마을의 생활권을 합친 규모를 한 마을에 적용한다는 기준으로 정했다. 이전 배치의 마을 사이 황무지까지 포함한 외접 사각형 면적을 합산한 값은 아니다.

각 마을에 주택 36채, 시장 4곳, 훈련 시설 4곳, 성당과 성소, 외곽 벽과 열린 출입구를 배치한다. 활동 목적지도 주거·시장·작업·훈련·내외곽 순찰로 분산했다. 시설 예약은 종류별로 4개 동시 이용 구역을 제공하고, 식량·약품·금고 초기값도 주민 증가율에 맞춰 7배로 조정했다.

## 거리와 배치

30초 기준은 **일반 걷기로 이웃 마을 경계에서 다음 마을 경계까지 이동하는 시간**이다. `PlayerWalkSpeed=3.7`이므로 도로 간격은 `3.7×30=111`칸, 마을 양쪽 반폭 18칸을 더한 중심 간격은 147칸이다. 달리기로 같은 구간을 이동하면 약 17.1초, 중심에서 중심까지 일반 걷기는 약 39.7초다. 전투·정지·개인적인 우회 시간은 이 수치에 포함하지 않는다.

| 마을 | 중심 | 문화 |
|---|---|---|
| 성당 마을 | (0, 0) | 자비와 상호부조 |
| 새벽 수도촌 | (-147, 0) | 신앙과 정화 |
| 철벽 주둔촌 | (0, 147) | 규율과 무력 |
| 황금 장터 | (147, 147) | 교역과 부의 축적 |
| 잿빛 탐구촌 | (-147, 147) | 탐험과 깨달음 |
| 검은 이빨 소굴 | (147, 0) | 약탈과 힘의 숭배 |

모든 마을에 같은 간격의 이웃이 생기도록 2행×3열 형태로 재배치했다. 직접 이웃을 연결하는 도로는 7개이고, 멀리 떨어진 마을은 여러 구간을 거쳐 간다. 성역 격자와 부활 위치 계산도 새 간격으로 통일했다.

도로 폭을 확보하고 마을 출입구를 비웠다. 장거리 경로는 마을 출구와 도로를 중간 목표로 삼으며, 기존의 33×33 지역 탐색과 12칸 경로 조각을 재사용한다. 일반 행동·시설 예약·원정·귀환 제한 시간은 커진 실제 이동 거리에 맞춰 계산한다.

확대된 시작 마을 안에 튜토리얼 몬스터가 나타나지 않도록 기존 경작지와 보스 구역은 동쪽으로 24칸 이동했다. 경작지 난수 지형도 마을 사이 주도로를 막지 않도록 처리했다. 청크 스트리밍과 공유 건물 리소스는 기존 방식을 사용한다.

## 전서구

- 기존 NPC 사절·상인의 방문과 소문 교환에 전서구를 추가했다.
- 마을별로 처음 3~13초에 발송을 시작하고 이후 24초마다 알려진 다른 마을에 번갈아 보낸다. 현지 주민이 모두 사라진 마을은 발송하지 않는다.
- 비행 속도는 12칸/초다. 직군별 보행 속도 1.8~2.5칸/초보다 빠르며, 인접 마을 중심 간 비행은 12.25초다.
- 출발 시점에 담은 마을 위치·성향·위험 보고를 비행 완료 후 전달한다. 보고의 원래 관측 시각과 출처는 그대로 보존한다.
- 발송 마을의 주민이 실제로 알고 있는 최근 살인·약탈·토벌·습격·광폭 사건을 최대 4건 함께 운반한다. 도착 사건은 원본 사건 ID를 가리킨다.
- 도착한 보고는 마을 게시망을 통해 그 마을에 실제 체류 중인 소속 주민에게 공유된다. 전투용 시야·적 위치 기억을 생성하지 않는다.
- 게임 장면에는 전서구 Actor가 비행하며, 날갯짓의 4개 메시 형태는 캐시를 재사용한다. 전서구는 주민·몬스터 인구와 별도로 집계한다.

전서구는 비행 중 처치·가로채기·분실 판정 없이 목적지로 이동하는 기본 통신 수단이다.

## 주민 이사

처음 25초 이후 10초 간격으로 마을별 이사 희망자를 검토한다. 건강하고 평시 상태이며 현재 고향에 있는 주민 중에서 선발한다. 원정·전투·광폭 상태와 수행 중인 플레이어 요청은 새 이사보다 우선한다.

주민은 마을에 전달된 보고를 바탕으로 자신의 성향과 목적지의 성향이 얼마나 맞는지, 몬스터 거점 및 적대 마을에 따른 위험이 얼마나 낮은지 비교한다. 240초보다 오래된 보고와 위험 보고가 있는 목적지는 제외하며, 성향 차이가 큰 마을도 제외한다. 목적지 점수가 현재보다 4점 넘게 좋아야 이사를 시작한다.

지리 위험의 몬스터 부분은 고정 배치된 거점을 알려진 지리 정보로 취급하여 거점과 마을 경계 사이 거리에 따라 계산한다. 적대 마을 위험은 전달받은 성향 보고와 마을 간 관계로 계산한다. 알려지지 않은 다른 마을의 실시간 성향이나 개별 NPC 위치를 이사 점수에 직접 사용하지 않는다.

이사 대상에게는 걸어서 도달할 새 집을 예약한다. 이미 거주 중인 집과 다른 이사자의 예약 위치는 중복 사용하지 않는다. 이동 중에는 기존 소속과 기존 집이 유지되고, 목적지 도착 시 새 소속·집·SceneGraph 부모를 함께 바꾼다. 재산·직군·태생 능력치·개인 관계·인물 ID는 계속 유지한다.

새 이사는 출발 예정 인원을 뺀 고향의 생존 주민 수가 50명 미만이 되지 않도록 제한한다. 전입 예약을 포함한 목적지 수용 인원은 최대 80명이다. 완료 후 일정 시간 재이사를 제한하며, 심각한 부상·광폭화·경로 실패·시간 초과 시 이사를 보류하고 현재 위치에서 생존 행동을 이어간다. 이동 중 전투와 사망도 실제 기존 전투 처리를 따른다.

50명 기준은 초기 배치 및 자발적 이사 출발 제한이다. 전투로 발생한 사망을 막거나 사망자를 자동 보충하는 기능은 추가하지 않았다. 순찰·원정·이사 중에는 실제 마을 안에 있는 체류 인원과 소속 인구가 다를 수 있다.

## 몬스터 거점

거점을 넓힌 마을 사이 황무지로 재배치하고, 병영과 외곽 구조물·개방된 출입구를 배치했다. 36개의 서로 다른 배치 위치를 사용하며 초기 12마리는 거점 안에 분산 배치한다. 빈 병력 슬롯은 8초 주기로 하나씩 보충한다.

순찰 반경은 18칸에서 시작해 40초마다 4칸씩, 최대 48칸으로 증가한다. 거점 주변 16칸 안에서 출격 대기 중인 병력이 24마리 이상이면 16마리 웨이브가 가까운 유인 마을로 출격한다. 먼 마을까지 도착할 수 있도록 습격 시간도 거리·이동 속도로 계산한다. 개별 추적·후퇴·복귀·피해 처리는 기존 전투를 사용한다.

## 성능과 분석 자료

주민 수가 7배가 되므로 전체 주민을 서로 대조하는 작업을 줄였다. 8칸 크기 공간 색인으로 시야·사건 목격·근거리 소문 교환에서 주변 주민만 찾는다. 색인은 기존 0.05초 고정 갱신에 맞추고, 사용하지 않는 빈 구역은 제거한다. 개별 사건 소문 처리는 3초마다 48명씩 순환한다. 336명이면 약 21초마다 한 번씩 자기 차례를 갖는다. NPC의 실제 행동과 이동 갱신은 모든 마을에서 계속 수행한다.

실제 FPS와 CPU·GPU 시간은 이번 작업에서 측정하지 않았다. 기존 프레임 프로파일러의 NPC 갱신 시간, 경로 호출/탐색 노드, 모니터 출력 시간, 인스턴스·드로우콜을 함께 비교할 수 있다.

시작 콘솔의 `[WorldScale]`과 `NpcAI/latest.log`의 `WORLD_SCALE`에 면적·인구·간격·속도·거점 정원을 남긴다. 주민별 이사 횟수·사유·예약 집, 마을별 전입·전출·전서구 송수신, 비행 중인 메시지의 목적지·도착 시각도 기록한다. 로그 파일은 기존 방식의 제한된 진단 스냅샷이며 저장 게임은 아니다.

모니터 메시지는 `schemaVersion=4`다. 서버는 기존 버전 1·2·3도 계속 받는다. 새 필드는 `carrierPosts`, `villageRoutes`, `settlementRules`, 주민의 `migration`, 마을의 전서구·전입·전출·위험 정보다. 상세 사건 보관량은 2048개로 늘렸다. HTML은 전서구 목록·지도 위치·이사 사건을 보여주며, 많은 주민의 이름이 겹치지 않게 지도에서 선택한 주민의 이름을 표시한다.

## 수행한 정적 검토

상세 결과: `마을_규모_확장_정적검토_2026-10-20.json`.

- 실제 헤더의 수치와 배치를 읽어 6개 마을, 7개 인접 도로, 모든 마을의 연결, 경계 간 30초를 확인했다.
- 저작된 건물·성당·성소 충돌에 몸체 여유 0.2칸을 더하고 0.5칸 격자로 통행 영역을 계산했다. 네 방향 출입구가 서로 연결되며, 56개 초기 집 위치 모두 근처에 도달 가능한 위치가 있다. 명목상 집 1곳은 성당과 가까워 기존 안전 배치 보정이 적용된다.
- 거점의 36개 병력 위치가 서로 다르고 구조물 충돌 영역을 피하는지, 직접 이웃 도로가 거점 영역과 겹치지 않는지 확인했다.
- 새 C++ 소스의 프로젝트·필터 등록, 코드 포맷, UTF-8/CRLF와 변경 공백을 확인했다.
- HTML 모니터의 JavaScript 구문 검사를 통과했다.

사용자 요청에 따라 빌드, 게임·서버 실행 및 실제 화면 확인은 하지 않았다. 모든 난수 시드의 경로, 실제 이사·전서구·습격 진행, 확대된 인구의 프레임 성능은 실행으로 확인할 항목이다.

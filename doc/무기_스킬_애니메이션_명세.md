# 주인공 무기 스킬과 애니메이션 제작 명세

## 사용 방법

대장간에서 장착한 무기의 전용 스킬을 Z로 사용한다. 순례자의 장검은 기존 주인공의 장검 메시로 장착할 수 있다. 기존 일곱 무기의 저장 번호를 유지하고 장검을 여덟 번째에 추가했다.

성소 밖의 인간 형태에서 사용할 수 있다. 시전 중 이동과 기본 공격을 잠시 멈춘다. 방향이 필요한 스킬은 발동 시 사거리 안에서 장애물에 가리지 않은 가장 가까운 대상을 향한다. 대상이 없으면 현재 모델이 보는 방향을 사용한다. 단검은 사거리 안에 대상이 있어야 한다.

스킬 재사용 시간은 발동 시점부터 진행되며, 장착 무기 교체와 저장·불러오기 후에도 남은 시간이 이어진다. 발동할 때 예약된 기본 공격을 취소하고 기본 공격 재사용 시간은 계속 흐른다. 사망, 괴물화, 대장간 열기는 남은 스킬 타격을 취소한다. 이미 발사된 화살은 각자의 탄도를 따라간다.

피해 배율은 레벨·강화·오염을 적용한 기본 공격력 기준이며, 대상의 방어는 기존 계산을 따른다. 직접 타격은 장애물과 성소 보호를 확인한다. NPC 공격 가능 여부는 기존 적대·PK 규칙을 따르고, 활은 기존 화살 충돌을 사용한다.

| 무기와 스킬 | 실제 판정 | 타격 시점 | 전체 동작 | 재사용 |
| --- | --- | --- | --- | --- |
| 지팡이 · 잔불의 문양 | 6칸 안에 지정한 지면의 반경 2.2칸에 불꽃 3회. 회당 0.65배 | 0.45 / 0.80 / 1.15초 | 1.40초 | 9초 |
| 활 · 가시 부채살 | 전방 48도에 화살 5발. 각 10칸, 0.80배. 근접한 큰 적에는 여러 발이 맞을 수 있음 | 0.55초 | 0.95초 | 8초 |
| 철퇴 · 방패 분쇄 | 전방 56도, 2.2칸에 1.35배. 몬스터의 보호막을 먼저 깨고 생존한 일반 적을 최대 1칸 밀어냄 | 0.38초 | 0.82초 | 7초 |
| 도끼 · 사형 집행 | 전방 170도, 3칸에 1.45배. 맞기 전 체력이 40% 이하인 적은 이 피해에 1.6배 추가 | 0.55초 | 1.05초 | 9초 |

지팡이는 발동 시 대상의 위치에 문양을 고정한다. 대상 없이 쓸 때는 앞쪽 사거리 안에서 첫 장애물 직전까지 전진한 지점에 놓는다. 철퇴의 밀치기는 벽 충돌을 적용하며 보스에게는 피해와 보호막 파괴만 적용한다.

## 애니메이션 제작 전달

기존 Hero 본 이름과 스킨을 유지한다. 무기별 장착 모델 GLB에 아래 클립 이름을 사용한다. 장검은 기존 장검·등불 리그 기준이다. 원점은 시전 위치에 고정하고 지면 이동은 0으로 만든다. 시작과 끝은 각 무기의 대기 자세에 맞춘다. 클립은 1회 재생으로 만들고, 위 표의 전체 동작 길이와 타격 시점을 그대로 사용한다.

타격 마커 이름은 `skill_contact`로 통일한다. 활의 마커에서는 화살을 놓는 손과 시위가 풀리는 모습이 같은 프레임에 보여야 한다. 게임은 장착 모델의 클립 길이와 카탈로그에 기록된 타격 마커를 시뮬레이션 시간에 적용한다. 피해와 발사는 화면의 렌더링 빈도와 독립적으로 처리된다. 애니메이션 팩에 클립을 등록할 때 기본 공격용 `melee_contact`, `cast_release`, `projectile_release` 대신 스킬 마커를 사용한다.

| 클립 이름 | 준비 → 타격 → 회수 |
| --- | --- |
| `HERO_Staff_SkillAshField` | 지팡이 끝에 재를 모아 들어 올리고, 0.45초에 지면으로 찍어 문양을 연다. 0.80·1.15초에 상체와 손에 짧은 맥동을 주고 대기로 복귀. |
| `HERO_Bow_SkillArrowFan` | 활을 올리고 한 번 크게 당긴다. 0.55초에 한 번 놓는 동작에 맞춰 화살 다섯 발이 퍼진다. 양손 반동 후 활을 내린다. |
| `HERO_Mace_SkillGuardBreak` | 철퇴를 몸 가까이 접어 두었다가 0.38초에 짧고 무겁게 전방으로 밀어 친다. 무게 중심을 되돌리고 철퇴를 회수한다. |
| `HERO_Axe_SkillExecution` | 도끼를 어깨 뒤에 크게 감는다. 0.55초에 반원에 가까운 낮은 횡베기를 내고, 팔과 상체의 관성을 살려 회수한다. |
| `HERO_Hammer_SkillGroundSlam` | 망치를 두 손으로 머리 위까지 들어 올린다. 0.72초에 망치 머리가 지면에 닿고, 충격을 무릎과 등으로 받은 뒤 무겁게 들어 올린다. 충격 범위는 망치 앞 부채꼴이다. |
| `HERO_Spear_SkillLongThrust` | 창대를 허리 뒤로 당긴다. 0.40초에 앞발을 디디며 끝까지 직선으로 뻗고, 뒤손으로 창대를 회수한다. 양손 파지가 미끄러지지 않게 한다. |
| `HERO_Dagger_SkillFlurry` | 반 보 자세를 낮춘다. 0.14초 짧은 찌르기, 0.27초 역방향 베기, 0.40초 마무리 찌르기를 같은 대상 높이에서 잇는다. |
| `HERO_Sword_SkillWhirlwind` | 0~0.15초에 칼을 감는다. 0.15~0.95초 사이 전신의 수직축 회전을 두 바퀴 굽고, 0.35·0.75초에 칼날이 원을 쓸고 지나가게 한다. 몸을 멈춰 대기로 복귀한다. |

2026-11-10 체형 개정본에는 장검 기본 모델과 장착 모델 7종의 전용 스킬이 들어 있다. 장검은 클립에 구워진 두 바퀴 회전을 재생하며, 활은 0.55초 발사에 맞춰 시위가 풀리고 장착 화살이 숨겨진다. 전용 클립이나 타격 마커가 유효하지 않은 에셋에서는 기존 공격 동작과 표의 타격 시간으로 대체한다. 장검의 코드 회전은 이 대체 동작에서 사용한다.

실행 확인은 성소 밖에서 Z로 각 무기를 시전한 뒤 타격 횟수, 장애물 뒤 대상, 대장간 교체 후 남은 재사용 시간, 망치 기절 중 적의 이동과 공격 여부를 보면 된다.

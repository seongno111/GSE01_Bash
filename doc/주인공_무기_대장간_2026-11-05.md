# 주인공 무기와 대장간

2026-11-05

각 마을 중앙에서 동쪽 6, 북쪽 좌표 2에 있는 기존 상업 건물을 대장간으로 지정했다. 월드 화면의 대장간 [E] 표식을 따라 건물 중심에서 2.8 이내로 접근한 뒤 E를 누른다. 선택 창에서 무기 카드를 클릭하면 즉시 장착된다. E, ESC 또는 닫기를 누르면 돌아간다. 화면 크기와 DPI에 맞춰 카드와 마우스 좌표를 변환한다.

현재 프로토타입에서는 교체가 무료이며 시작 무기는 재의 순례 지팡이다. UI를 열면 플레이어 이동과 자동 공격 입력을 잠시 멈춘다. 월드 시뮬레이션은 진행하며, 사망하면 UI를 닫는다. 강화 단계는 모든 무기에 공통으로 적용된다.

| 이름 | 방식 | 기본 공격력 | 기본 공격 간격 | 사거리 |
| --- | --- | --- | --- | --- |
| 재의 순례 지팡이 | 원거리 불씨 | 24 | 0.90초 | 6.0 |
| 가시 사냥 활 | 원거리 화살 | 20 | 0.74초 | 9.0 |
| 흑철 날개 철퇴 | 단일 대상 근접 | 38 | 0.95초 | 1.6 |
| 갈라진 전투 도끼 | 단일 대상 근접 | 44 | 1.10초 | 1.9 |
| 수문장 전투 망치 | 단일 대상 근접 | 65 | 1.55초 | 1.8 |
| 잿빛 장창 | 단일 대상 근접 | 31 | 0.85초 | 3.0 |
| 황동 가드 단검 | 단일 대상 근접 | 15 | 0.32초 | 1.2 |

SPACE를 누르거나 F로 자동 공격을 켜면 사거리 안의 보이는 대상을 공격한다. 근접 무기는 선택된 대상에게 직접 피해를 주고, 원거리 무기는 충돌 검사를 하는 발사체를 생성한다. 활은 팩에 포함된 철촉 화살 모델을 사용한다. 교체로 기존 공격 쿨타임을 취소할 수 없다.

공격력은 기본값에 레벨당 5, 강화 단계당 4, 오염당 0.3을 더한다. 공격 간격은 레벨마다 0.94배가 되며 기본 수치의 25%와 전용 공격 동작 길이의 1/3 중 큰 값을 하한으로 둔다. 활은 장전부터 회수까지 2.22초짜리 동작을 최대 3배속으로 재생하므로 기본 실제 간격은 0.74초다. 카드에는 이 보너스가 적용된 현재 값이 표시된다. 수치는 SimpleGame/HeroWeapons.h에서 관리하며 전투와 UI가 같은 계산 함수를 사용한다.

무기 미리보기는 Modeling/HeroWeapons_v1의 개별 GLB를 사용한다. 장착 모델은 Modeling/HeroWeaponAnimations_v1의 무기별 GLB를 우선 사용하며, 이 모델에는 이미 무기가 스킨에 포함되어 있어 별도 무기를 중복 장착하지 않는다. 전용 팩이 없거나 해당 무기 로딩에 실패하면 기존 정적 장착 방식으로 돌아간다. 활·망치·창은 등불 메시와 광원을 숨기며, 지팡이·철퇴·도끼·단검은 등불을 유지한다.

무기 선택 화면은 실제 GLB 메시를 렌더링한다. 무기 카드의 모델 투영 범위가 텍스트 영역을 침범하지 않는지 원본 정점으로 검사했다. Visual Studio 프로젝트, 필터, 무기 카탈로그 배포 항목을 추가했다.

무기별 대기·공격과 공통 이동의 상체 조합을 적용했다. 지팡이와 근접 무기는 두 공격 동작을 번갈아 사용하며 피해 판정과 탄체 생성은 카탈로그의 타격·발사 시점에 실행한다. 활은 장전 → 당김 → 조준 → 발사 순서로 동작한다. 자세한 설정과 확인 항목은 주인공_무기별_애니메이션_적용_2026-11-05.md에 기록했다. 변이 상태는 기존 괴물 동작과 선택 무기의 전투 수치를 사용한다.

빌드와 게임 실행은 사용자가 확인한다. E 접근, 카드 클릭, 활의 왼손 장착, 근접 사거리, 원거리 장애물 충돌, 창 크기 변경, 교체 후 쿨타임을 확인하면 된다.

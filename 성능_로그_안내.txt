기본 성능 로그

게임 실행 중 약 1초마다 콘솔에 다음 형식으로 출력한다.
아래 숫자는 형식을 설명하기 위한 예시이며 측정 결과가 아니다.
  [Profile] FPS=60.0 | DrawCalls/frame: last=350 avg=347.2 min=340 max=362

FPS
  실제 완료한 Display 프레임 수 / 실제 경과 시간(초).
  steady_clock을 사용하며 게임 갱신용으로 제한된 dt는 사용하지 않는다.
  업데이트, 타이머 대기, 버퍼 교환과 콘솔 출력에 걸린 시간도 반영한다.
  GPU 실행 시간이나 모니터에서 실제 표시한 프레임 수를 측정하는 값은 아니다.

DrawCalls/frame
  last: 마지막으로 완료한 한 프레임의 glDraw 호출 횟수.
  avg / min / max: 해당 출력 구간에서 프레임당 평균 / 최소 / 최대 횟수.
  Renderer::Begin에서 초기화하고 실제 glDrawArrays 호출 위치마다 1씩 증가한다.
  캐시 메시, 동적 배치, 한글 UI, Bloom·블러·최종 합성을 모두 포함한다.
  glDrawBuffer, glClear, 버퍼 업로드, 버퍼 교환은 드로우콜로 세지 않는다.
  현재 그리기 명령은 모두 glDrawArrays이며, 새 glDraw 계열 호출을 추가할 때도
  해당 렌더러의 호출 직후 카운터를 증가시켜야 한다.
  후처리가 꺼진 프레임도 후처리 카운터를 초기화하여 이전 프레임 값을 남기지 않는다.

프레임마다 수집하되 콘솔 출력은 1초 간격으로 제한한다.
FrameProfiler.cpp의 출력 간격 조건에서 이 주기를 변경할 수 있다.
GPU 동기화나 glFinish를 추가하지 않는다.
사용자 요청에 따라 빌드·실행·실측 확인은 진행하지 않았다.

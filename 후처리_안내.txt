렌더링 후처리 안내
작성일: 2026-09-08

적용 내용
  장면 전체를 HDR 렌더 타깃에 그린 뒤 블룸, 가장자리 블러,
  비네트와 톤 매핑을 적용하도록 구성했다.
  효과는 기본적으로 모두 켜져 있으며 실행 중 개별 비교가 가능하다.
  기존의 좌우 세로 띠 비네트는 제거했다.
  광원 주위에 직접 그리던 타원형 Glow와 성소·플레이어 바닥의
  빛 번짐 도형도 제거했다. 불꽃, 불티, 등불, 성당 창문과 괴물 눈의
  발광 픽셀을 HDR 장면에서 추출해 후처리 블룸으로만 번짐을 만든다.
  안개용 그라데이션은 광원 효과와 별개로 유지한다.
  HUD, 한글 메시지, 잔재 이름과 체력 바는 후처리 이후에 그린다.

실행 중 조절
  P     전체 후처리 켜기/끄기
  B     블룸 켜기/끄기
  V     비네트 켜기/끄기
  N     가장자리 블러 켜기/끄기
  [ / ] 노출 감소/증가 (0.25 ~ 3.0)
  0     후처리 기본 설정 복원
  H     기존 조작 안내와 후처리 상태 패널 표시/숨기기
  효과 설정은 종료하면 초기화되며 게임의 오염·전투 수치를 바꾸지 않는다.

렌더링 순서
  1. 장면 색상을 sRGB에서 선형 공간으로 변환
  2. 불꽃·횃불·괴물 눈 등에 별도의 발광 강도 적용
  3. 원본 해상도 GL_RGBA16F 텍스처에 장면 렌더링
  4. 임계 밝기 이상의 색상을 추출하고 절반 해상도로 축소
  5. 두 텍스처를 번갈아 사용하며 가로·세로 가우시안 블러로 블룸 생성
  6. 별도의 절반 해상도 텍스처에 장면 블러 생성
  7. 화면 중심에서 모서리로 갈수록 원본과 블러 장면을 혼합
  8. 블룸 합성과 부드러운 비네트 적용
  9. 노출 조절과 ACES 곡선 근사 톤 매핑 후 sRGB로 변환
  10. UI와 한글 대사를 선명하게 합성

조정 위치
  SimpleGame/PostProcessing.h의 PostProcessSettings
    exposure           기본 1.15 : 장면의 노출
    bloomThreshold     기본 1.0  : 선형 RGB 최대 채널의 발광 추출 기준
    bloomKnee          기본 0.5  : 추출 경계의 부드러움
    bloomStrength      기본 0.30 : 블룸 합성 강도
    bloomRadius        기본 2.4  : 블룸 블러 샘플 간격
    vignetteStrength   기본 0.52 : 모서리 암부 강도
    vignetteStart      기본 0.30 : 비네트 시작 거리
    edgeBlurStrength   기본 0.85 : 모서리에서 블러 장면을 섞는 비율
    edgeBlurStart      기본 0.43 : 블러 시작 거리
    edgeBlurRadius     기본 3.0  : 블러 샘플 간격

  거리 기준은 화면 중심 0, 모서리 1인 타원형 마스크다.
  시작 거리는 0 이상 1 미만, 혼합 강도는 0~1을 기준으로 조정한다.
  블룸과 가장자리 블러 반경은 창 높이 800 기준의 절반 해상도 픽셀 단위이며
  창 높이에 비례하도록 처리한다. 확대·축소 키와는 독립적이다.

  SimpleGame/Prototype.cpp의 Color(...).Radiance(강도)
    성소 불꽃, 불티, 횃불, 성당 등불·창문, 괴물의 눈에 사용한다.
    기본 색을 선형 공간으로 변환한 뒤 강도를 곱하므로 1을 넘는
    밝기를 렌더 타깃에 저장할 수 있다.
    일반 지형은 기본 강도 1을 유지한다.

주요 파일
  PostProcessing.h / PostProcessing.cpp
    HDR 렌더 타깃과 후처리 패스 관리, 리사이즈, 자원 해제.
  ShaderProgram.h / ShaderProgram.cpp
    장면·후처리 셰이더에서 함께 사용하는 파일 로딩과 컴파일/링크 처리.
  Shaders/Fullscreen.vs
    화면 전체를 채우는 삼각형.
  Shaders/BloomExtract.fs
    밝은 부분 추출과 축소. 임계값 0이면 일반 장면 축소에 사용.
  Shaders/GaussianBlur.fs
    가로·세로 분리 블러.
  Shaders/PostComposite.fs
    가장자리 블러, 블룸, 비네트, 노출, 톤 매핑과 출력 변환.
  Renderer::BeginUI()
    장면 배치를 비우고 후처리를 끝낸 뒤 UI 렌더링 단계로 전환.

범위와 실패 대응
  여기서 HDR은 내부 장면의 높은 밝기 범위를 뜻한다.
  최종 출력은 일반 SDR 화면이며 HDR10 모니터 출력 구현은 아니다.
  톤 매핑은 ACES 곡선을 근사한 방식으로 전체 ACES 색 관리 파이프라인은 아니다.
  블러는 화면 위치 기반이며 깊이 버퍼를 사용하는 피사계 심도 효과는 아니다.
  기존 도형 기반 광원 표현을 유지하며 물리 기반 조명·그림자는 후속 과제다.
  창 크기가 바뀌면 HDR와 블러 텍스처를 다시 할당한다.
  새 셰이더는 기존 빌드 후 복사 규칙에 포함된다.
  셰이더 또는 HDR 렌더 타깃 생성 실패 시 콘솔에 원인을 출력하고
  직접 렌더링으로 돌아간다. 안내 패널에도 실패 상태를 표시한다.

사용자가 확인할 항목
  - P로 전환했을 때 후처리 전후의 차이가 있는지
  - 성소 불꽃의 밝은 중심과 주변 블룸이 구분되는지
  - B를 껐을 때 빛 번짐만 제거되는지
    (밝은 불꽃·등불 자체는 남고, 광원 주변 타원형 후광은 없어야 함)
  - V와 N으로 모서리 어두움과 흐려짐을 각각 비교할 수 있는지
  - 화면 중심과 플레이어의 가독성이 유지되는지
  - 한글 대사·상태창이 흐려지거나 빛나지 않는지
  - 창 리사이즈, 작은 창, 다른 화면 비율에서 깨짐이 없는지
  - 효과 적용 시 성능과 기본 노출이 적절한지

사용자 요청에 따라 이번 작업에서 빌드·실행·시각 결과 검증은 수행하지 않았다.
기본 강도는 첫 조정을 위한 값이며, 실제 화면을 보고 조율해야 한다.

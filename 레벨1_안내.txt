레벨 1 · 버려진 경작지
작성일: 2026-09-14

이 문서는 기존 프로토타입_안내.txt보다 최신 게임 규칙을 설명한다.
레벨 1은 지역/입문 단계이며, 캐릭터의 경험치 레벨과는 별개다.

1. 목표와 플레이 흐름
  시작 성소에서 안전하게 준비하고 동쪽 경작지에서 파밍을 익힌다.
  목표는 HUD에 순서대로 표시하며 녹색 화살표로 목표 방향을 안내한다.

  - SPACE를 유지하여 적 3마리 처치
  - 드랍 아이템에 접근하여 4개 습득
  - 캐릭터 레벨 3 이상, 누적 처치 6마리 달성
  - 보스 '경작지 수문장' 처치
  - 시작 성소(월드 좌표 0, 0)로 돌아와 E로 보고

  완료 보상: 성물 1개, 회복약 2개, 경험치 60. 최초 한 번만 지급한다.
  보고에 강화 파편을 소모하지 않으므로 파밍 중 자유롭게 강화할 수 있다.
  완료 뒤에도 재등장하는 적과 보스를 계속 사냥할 수 있다.

2. 조작
  WASD  : 화면 기준 이동
  SPACE : 누르는 동안 자동 조준 사격
  F     : 완전 자동 사격 켜기/끄기 (기본 꺼짐)
  U     : 강화 파편 3개로 무기 1단계 강화
  Q     : 소지한 회복약 사용
  T     : 소지한 정화석 사용
  E     : 성소에서 회복·정화 / 시작 성소에 보스 처치 보고
  R     : 괴물 상태에서 성물로 인간 복귀
  H     : 도움말 표시/숨기기 (목표와 경험치 바는 유지)
  G     : 청크 경계와 현재 실행의 월드 시드 표시
  +/-   : 확대/축소
  K     : 기존 개발용 사망 시연
  ESC   : 종료
  P/B/V/N, [/], 0 : 기존 HDR 후처리 조절 유지

3. 자동 조준과 원거리 공격
  기본 사거리는 월드 기준 6타일이다.
  사거리 안에서 장애물에 가리지 않은 가장 가까운 살아 있는 적을 선택한다.
  일반 적, 보스, 기존 잔재 몬스터를 모두 조준할 수 있다.
  선택된 적은 금색 표식으로 표시하고, 사격 중에는 점선 사거리도 표시한다.
  적이 없으면 발사하거나 쿨타임을 소모하지 않는다.
  발사체는 조준 당시의 방향으로 직진한다. 발사 후 유도탄처럼 방향을 바꾸지 않는다.
  최대 6타일 이동하면 소멸하며, 장애물 또는 첫 번째 적에 충돌하면 사라진다.
  짧은 이동 단계로 충돌을 처리하여 고속 이동 중 적이나 벽을 통과하는 문제를 줄인다.
  화면상의 발사체는 HDR 발광 픽셀로 그려 기존 Bloom에 연결한다.

4. 경험치와 성장
  캐릭터는 1레벨에서 시작하며 현재 프로토타입의 최대 레벨은 50이다.
  경험치는 일반 적·보스 처치, 불의 정수 습득, 최초 입문 완료 보상으로 획득한다.

  최대 체력 = 100 + 15 x (레벨 - 1)
  발사체 피해 = 24 + 5 x (레벨 - 1) + 4 x 무기 강화 단계 + 0.3 x 오염
  발사 간격 = 0.90 x 0.94^(레벨 - 1)초, 최소 0.22초
  다음 레벨 필요 경험치 = 40 + 25 x (레벨 - 1)

  남는 경험치는 다음 레벨로 이월하며 한 번에 여러 레벨을 올릴 수 있다.
  레벨업 시 새로 늘어난 체력 15와 새 최대 체력의 20%만큼 회복한다.
  정화는 오염으로 얻은 피해 증가만 줄인다. 레벨과 무기 강화는 유지된다.
  무기 강화는 최대 +10이며 단계마다 파편 3개를 소모한다.

5. 아이템 드랍과 자석 습득
  금색 / 강화 파편
    일반 적에게서 1개, 보스에게서 3개를 기본 획득한다. U로 강화에 사용한다.
  붉은색 십자 / 체력 회복
    습득 즉시 최대 체력의 35%를 회복한다. 체력이 가득 차 있어도 소모된다.
  주황색 / 불의 정수
    일반 정수는 경험치 25, 보스 추가 정수는 경험치 80을 즉시 지급한다.
  푸른색 / 정화석
    소지품으로 보관하고 T로 사용한다. 괴물화 이전 오염을 25 줄인다.
    오염이 없거나 괴물화한 상태에서는 소모하지 않는다.
  초록색 / 자석 강화
    15초 동안 자동 습득 반경을 2.4타일에서 5.5타일로 늘린다.
    다시 획득하면 지속시간을 15초로 갱신한다.

  추가 드랍은 회복 → 불의 정수 → 정화석 → 자석 순으로 순환한다.
  입문 단계에서 각 아이템을 반드시 접하도록 선택한 임시 드랍 규칙이다.
  보스는 기본 드랍에 불의 정수와 정화석을 추가로 준다.
  기본적으로 아이템은 가까이 가면 끌려오며, 거리가 0.65타일 이내면 자동 습득한다.
  자석 이동과 습득에 장애물 확인을 적용하며, 드랍 위치가 막혔다면 사망 지점으로 보정한다.
  지면 아이템은 60초 뒤 사라진다.

  시작 소지품: 회복약 2개, 성물 1개.
  소지 회복약(Q)은 최대 체력의 45%를 회복하고, 체력이 가득 차면 소모하지 않는다.
  지면 회복 아이템과 소지 회복약은 별개의 회복 수단이다.

6. 랜덤 맵과 이동 안전
  매 실행 시 월드 시드를 생성한다. 같은 실행 안에서는 청크를 다시 불러와도 지형이 같다.
  레벨 1은 시작 성소 옆 x=4~22, y=-3~13의 경작지에 구성된다.
  경작지 밖으로도 기존 오픈 월드 탐험을 계속할 수 있다.
  적의 시작 위치와 장애물은 시드에 따라 달라진다.

  생성 순서:
    랜덤 장애물 배치 → 폭 2타일의 주 통로 확보 → 적·보스의 전투 공간 확보
    → 각 공간을 주 통로에 연결 → 시작점에서 4방향 탐색으로 도달 영역 계산
    → 연결되지 않은 빈 공간을 장애물로 채움

  경작지 테두리에도 통로를 두어 외부로 나가는 길을 유지한다.
  경작지 밖은 4타일 간격의 장애물 없는 통로를 확보하고 성소 주변을 비운다.
  플레이어는 성소의 안전 반경 안에서 시작·부활한다.
  경작지 적은 직선 추적이 막히면 연결된 타일을 탐색하여 우회한다.
  실제 충돌은 기존 원형 근사 방식이므로 좁은 모서리의 이동감은 실행 후 조정이 필요하다.

7. 일반 적과 보스
  메마른 망자: 체력 45, 접촉 공격 피해 8, 처치 경험치 20.
  오염된 약탈자: 체력 75, 접촉 공격 피해 12, 처치 경험치 30.
  일반 적은 공격 전에 붉은 예고를 보여 주며, 거리를 벌리면 피할 수 있다.
  일반 적 7개 배치 지점을 두고 사망 25초 뒤 재등장한다.
  플레이어가 배치 지점 3.5타일 안에 있으면 안전을 위해 재등장을 미룬다.

  보스: 경작지 수문장
    등장 조건: 레벨 3 이상, 누적 처치 6마리 이상, 아이템 4개 이상 습득.
    체력 380, 근접 공격 피해 20, 처치 경험치 80.
    0.9초 충격파 예고 뒤 8방향 발사체를 방출한다. 기본 피해는 14다.
    체력 40% 이하에서는 격노하여 이동 속도가 증가하고
    12방향 발사체(피해 18)를 더 짧은 주기로 방출한다.
    별도의 보스 체력 바와 격노 표시를 제공한다.
    처치 45초 뒤 재등장할 수 있으며, 가까이 있는 플레이어 위로 즉시 생성하지 않는다.
    시작 성소 보고 보상은 재등장한 보스를 잡아도 중복 지급하지 않는다.

8. 기존 오염 시스템과 연결
  사망 시 오염 +25, 100 이상에서 괴물화, 최대 150 규칙을 유지한다.
  괴물 상태에서 죽으면 레벨·체력·공격력 증가를 반영한 잔재가 남는다.
  잔재는 이번 단계에서도 근접 추적형이며 발사체 기술 자체는 계승하지 않는다.
  잔재 처치는 경험치와 파밍 아이템을 지급하지 않는다.
  사망으로 파밍 보상을 무한 복제하는 경로를 만들지 않기 위한 규칙이다.
  사망해도 레벨·경험치·강화·소지품·입문 목표 진행도는 유지한다.
  사망 시 남은 발사체를 제거하고 경작지 적의 위치·체력·공격 예고를 초기화한다.
  이미 처치한 적의 재등장 타이머는 유지한다.
  괴물화한 상태는 정화석·일반 성소로 복귀할 수 없고 성물(R)이 필요하다.

9. 코드와 현재 범위
  LevelOne.cpp: 레벨 생성, 조준·발사체, 적·보스, 경험치·드랍, 목표·성장 UI.
  Prototype.h: 게임플레이 상태와 자료구조.
  Prototype.cpp: 기존 월드·오염 시스템과 연결, 입력 및 장면 표시.
  코드 스타일은 프로젝트의 Allman 중괄호와 줄바꿈 규칙을 따른다.

  현재 수치는 첫 플레이 조정을 위한 값이다.
  영구 저장, AI NPC 대화, 장비 교체와 정식 인벤토리 화면은 아직 포함하지 않는다.
  종료하면 월드 시드, 레벨, 아이템과 진행도가 초기화된다.
  별도 요청이 없으므로 빌드·실행·플레이 결과 확인은 수행하지 않았다.

10. 사용자 확인 항목
  사냥 → 습득 → 강화 → 레벨업 → 보스 → 성소 보고 흐름의 이해도.
  무표적·사거리 밖·벽 뒤에서는 발사하지 않는지와 실제 발사체 충돌.
  레벨업 뒤 최대 체력, 피해, 발사 간격이 HUD와 일치하는지.
  다섯 종류 드랍과 자동 습득, 자석 시간, Q/U/T 사용 조건.
  괴물 상태에서 정화석을 사용해도 소비·정화되지 않는지.
  여러 실행의 랜덤 지형에서 시작점·파밍 구역·보스까지 이동 가능한지.
  보스 예고와 격노 패턴, 처치 및 최초 보고 보상.
